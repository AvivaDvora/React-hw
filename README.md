# מערכת הרשמה לסדנאות וחוגים

אפליקציית תרגול ב־React לניהול סדנאות, הרשמת משתתפות ובדיקת מקומות פנויים. הפרויקט משמש שיעור מעשי ומציג תחילה ניהול נתונים מקומי, ולאחר מכן חיבור לשרת Node.js באמצעות `useEffect` ו־Fetch API.

האפליקציה בעברית ותומכת בחיפוש, סינון לפי קטגוריה והצגת סדנאות עם מקום פנוי בלבד.

## יכולות

- הצגת סטטיסטיקות: סדנאות פעילות, נרשמות, מקומות פנויים וסדנאות מלאות
- הוספת סדנה עם שם, מנחה, קטגוריה ומספר מקומות
- חיפוש לפי שם סדנה או מנחה
- סינון לפי קטגוריה ולפי זמינות
- הרשמה וסגירת הרשמה לסדנה
- מחיקת סדנה
- מניעת הרשמה כפולה ומניעת חריגה ממספר המקומות
- שתי שכבות נתונים: State מקומי או שרת API

## טכנולוגיות

## שני מצבי עבודה

### מצב מקומי — חלק א' של השיעור

מצב ברירת המחדל משתמש בנתונים מתוך `src/data/initialWorkshops.js` וב־State מקומי:

```js
// src/main.jsx
import App from './App.jsx';
```

כל הפעולות מתבצעות בצד הדפדפן ואינן נשמרות לאחר רענון הדף.

### חיבור לשרת Node.js — חלק ב' של השיעור

כדי להשתמש ב־`AppWithApi.jsx`, החליפו ב־`src/main.jsx` את ה־import כך:

```js
import App from './AppWithApi.jsx';
```

האפליקציה מצפה ל־API בכתובת:

```text
http://localhost:3000/api/workshops
```

ניתן לשנות את כתובת הבסיס ב־`src/services/workshopsApi.js`.

יש להפעיל שרת Node.js נפרד ולהגדיר CORS כדי לאפשר בקשות מהאפליקציה. לדוגמה, כאשר משתמשים ב־Express:

```bash
npm install cors
```

```js
const cors = require('cors');

app.use(cors());
```

### נקודות קצה נדרשות

| פעולה | Method | נתיב | גוף בקשה לדוגמה |
|---|---|---|---|
| שליפת הסדנאות | `GET` | `/api/workshops` | — |
| יצירת סדנה | `POST` | `/api/workshops` | `{ "title": "סדנה", "instructor": "מנחה", "category": "אומנות", "maxSpots": 5 }` |
| הרשמה לסדנה | `PATCH` | `/api/workshops/:id/register` | `{ "name": "שרה כהן" }` |
| ביטול הרשמה | `PATCH` | `/api/workshops/:id/unregister` | `{ "name": "שרה כהן" }` |
| מחיקת סדנה | `DELETE` | `/api/workshops/:id` | — |

תגובה להרשמה, ביטול הרשמה או יצירה צריכה להחזיר אובייקט סדנה מעודכן בפורמט JSON. לדוגמה:

```json
{
  "id": 1,
  "title": "סדנת קליגרפיה",
  "instructor": "חני לוי",
  "category": "אומנות",
  "maxSpots": 4,
  "participants": ["שרה כהן"]
}
```

```text
│   └── initialWorkshops.js # נתוני התחלה וקטגוריות

```

## מושגי React בתרגול

- `useState`: אחסון מצב מקומי בקומפוננטות ובאפליקציה
- Props ו־Callbacks: העברת נתונים ופונקציות בין קומפוננטות
- Immutability: עדכון מערכים ואובייקטים באמצעות spread ו־`map`
- Derived State: חישוב נתונים מסוננים וסיכומים במקום לשמור אותם כ־State נוסף
- Controlled Components: שמירת ערכי שדות הטופס ב־State
- `useEffect`: טעינת נתונים מהשרת בעת עליית הקומפוננטה
- מצבי טעינה ושגיאה: טיפול במצב `loading`, שגיאת רשת ומצב הצלחה
- Cleanup: מניעת עדכון State אחרי שהקומפוננטה ירדה מהמסך


## רענון נתונים

במצב מקומי, כל שינוי נשמר בזיכרון הדפדפן בלבד ונעלם ברענון. במצב API נשמרים השינויים בשרת, בהתאם לנקודות הקצה ולבסיס הנתונים שתגדירו בצד Node.js.

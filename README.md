# ניהול קורסים, סטודנטים והרשמות

אפליקציית React לניהול קורסים, סטודנטים וההרשמות ביניהם. הפרויקט משמש שיעור מעשי ומדגים שתי שכבות נתונים מתחלפות: מצב מקומי בדפדפן או שרת Node.js — באמצעות `useEffect` ו-Fetch API.

האפליקציה בעברית ומותאמת לכיווניות מימין־לשמאל.

## יכולות

- **סטטיסטיקות:** מספר קורסים, קורסים פתוחים להרשמה, קורסים סגורים, סטודנטים והרשמות
- **הוספת קורס:** שם, תיאור וקטגוריה
- **הוספת סטודנט:** שם וגיל
- **הרשמת סטודנט לקורס** ועריכת הרשמות
- **חיפוש:** לפי שם קורס או תיאור, ולפי שם סטודנט
- **סינון:** לפי קטגוריה, ולפי קורסים שפתוחים להרשמה בלבד
- **פתיחה וסגירת הרשמה** לקורס
- **מחיקה:** קורס, סטודנט או הרשמה
- **מניעה:** הרשמה כפולה לאותו קורס, והרשמה לקורס שההרשמה אליו סגורה
- **שתי שכבות נתונים:** מצב מקומי או שרת API — נבחר במשתנה סביבה

## טכנולוגיות

## בחירת שכבת הנתונים

המצב נקבע במשתנה `VITE_DATA_MODE` שבקובץ `.env`:

```bash
# מצב מקומי — נתונים בזיכרון הדפדפן (חלק א' של השיעור)
VITE_DATA_MODE=local

# חיבור לשרת Node.js (חלק ב' של השיעור)
VITE_DATA_MODE=api
```

**שימו לב:** יש להפעיל מחדש את `npm run dev` אחרי שינוי ב-`.env`.

### מצב מקומי

הנתונים מגיעים מ-`src/data/seedData.js` ונשמרים בזיכרון בלבד (`src/services/localStore.js`). כל השינויים נעלמים ברענון הדף.

### מצב API

האפליקציה פונה לשרת לפי הכתובות ב-`src/services/workshopsApi.js`:

```text
http://localhost:3000
```

יש להפעיל שרת Node.js נפרד ולהגדיר CORS. לדוגמה עם Express:

```bash
npm install cors
```

```js
const cors = require('cors');

app.use(cors());
```

### נקודות קצה נדרשות

| פעולה | Method | נתיב | גוף בקשה לדוגמה |
|---|---|---|---|
| שליפת קורסים | `GET` | `/courses` | — |
| יצירת קורס | `POST` | `/courses` | `{ "name": "קורס", "description": "תיאור", "category": "כללי" }` |
| עדכון קורס | `PUT` | `/courses/:id` | `{ "name": "קורס", "description": "תיאור", "category": "כללי" }` |
| מחיקת קורס | `DELETE` | `/courses/:id` | — |
| שליפת סטודנטים | `GET` | `/students` | — |
| יצירת סטודנט | `POST` | `/students` | `{ "name": "סטודנט", "age": 20 }` |
| שליפת הרשמות | `GET` | `/enrollment` | — |
| יצירת הרשמה | `POST` | `/enrollment` | `{ "studentId": 1, "courseId": 2 }` |
| מחיקת הרשמה | `DELETE` | `/enrollment/:id` | — |

כל התשובות צריכות להיות JSON במבנה `{ "data": ... }`. לדוגמה:

```json
{
  "data": {
    "id": 1,
    "name": "קורס לדוגמה",
    "description": "תיאור לדוגמה",
    "category": "כללי",
    "isOpen": true
  }
}
```

בשגיאה, השרת יכול להחזיר `{ "error": "הודעת שגיאה" }` — היא תוצג למשתמשת.

## מושגי React בתרגול

- `useState`: אחסון מצב מקומי
- Props ו־Callbacks: העברת נתונים ופונקציות בין קומפוננטות
- Immutability: עדכון מערכים ואובייקטים באמצעות spread ו־`map` / `filter`
- Derived State: חישוב רשימות מסוננות וסטטיסטיקות במקום לשמור אותן כ־State נוסף
- Controlled Components: שמירת ערכי שדות הטופס ב־State
- `useEffect`: טעינת נתונים בעת עליית הקומפוננטה
- מצבי טעינה ושגיאה: טיפול ב־`loading`, שגיאת רשת ומצב הצלחה
- Cleanup: מניעת עדכון State אחרי שהקומפוננטה ירדה מהמסך

## מגבלות ידועות

- **אין מספר מקומות לקורס.** לכן אין "מקומות פנויים" ואין מניעת חריגה ממספר מקומות.
- **המצב המקומי אינו נשמר.** הנתונים חיים בזיכרון בלבד ומתאפסים ברענון הדף.
- **מפתח ה־auth אינו סוד אמיתי.** כל משתנה `VITE_*` נחשף בקוד ה־build; אימות אמיתי צריך להתבצע בשרת.
